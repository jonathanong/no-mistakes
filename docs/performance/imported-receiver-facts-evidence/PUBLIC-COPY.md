# Public evidence copy

This directory is a transformed public copy. Original evidence remains immutable
locally at commit `3983956b20f32a937e82e8bd39009bf9b55f6de6`.

Internal absolute roots use explicit placeholders such as `<WORKSPACE>`,
`<SYSTEM>`, `<RUST_SOURCE>`, and `<TEMP>`. Replace them with local roots to
reproduce scripts. These are visible substitutions, not encoded original paths.
Detailed Cargo artifact JSONL, build/link logs, environment/cache metadata and
superseded raw manifests are withheld. Summaries retain compiler versions,
features, flags, revisions, artifact hashes and measured results.

All 25 full instruction-work profiles, including normalized compressed copies, are
withheld locally. The public package contains readable annotated summaries,
numeric instruction-work records, and measurement tables. Full profiles are not
durably included in this public package. `public-copy-mapping.json` records
original and withheld normalized hashes and omissions.
The original timing observations and original artifact hashes are unchanged.
