# Download integrity effort fixture

Each active workflow path and the composite action has one literal unsafe URL
and one URL recovered from a single uppercase literal assignment. At `max`, all
four downloads are findings. At `low`, the two literal URLs remain findings and
the two assigned URLs follow the selected `unanalyzable` policy: report gives
four findings, advise gives two findings and two advisories, and ignore gives
two findings. The default configuration must match explicit `max`.

The other steps cover same-step checksum verification, checksum-file URLs,
trusted hosts, the `integrity-check: skip` marker, and URL-looking header/output
arguments. They must not add findings or unanalyzable diagnostics. Separate
steps and a file-suppressed workflow exercise line, next-line, and file
directives without changing those counts.
